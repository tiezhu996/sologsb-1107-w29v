# 手工造纸帘纹与工序档案

围绕手工造纸的纸帘、纤维料批、抄纸工序与成纸样本建立一体化档案。界面可登记纸帘丝径与帘纹间距、推算网目密度，跟踪料批打浆度，复测抄纸帘纹偏差，并按匀度与帘纹条数复核样本。所有业务数据保存在浏览器 IndexedDB 中，无需后端服务。

## Docker 一键启动

```bash
cp .env.example .env && docker compose up -d --build
```

默认映射端口为 `21807`。启动后访问 `http://localhost:21807`。

## 数据存储说明

数据存储使用 IndexedDB，Dexie 数据库名为 `gbpapermill-db`。

- `version(1)`：建立 `moulds`、`fiberBatches`、`sheetRuns`、`paperSamples` 四张表及编号、日期、状态等索引。
- `version(2)`：为四张表加入 `schemaRev` 索引，并通过 `upgrade` 将存量记录回填为版本 `2`。
- `version(3)`：新增 `mouldVersions`（维修版本快照）、`recheckRecords`（复检记录）、`recalcBatches`（重算批次，含重算前后结果）三张表，并为工序/样本补充时点匹配与复检状态索引。升级时自动为每张纸帘补一条建帘基线快照、按工序日期回填命中版本/标准间距/偏差，旧工序缺参数时标为“待补录”。
- 数据库首次创建时通过 `populate` 写入 5 张纸帘（含建帘基线与一版早期维修）、5 个纤维料批、8 槽抄纸工序和 6 个成纸样本。
- 页面顶部的“导出 JSON”会下载全部七张表的完整备份；存在重算批次时另附一份重算前后对照 CSV。

## 纸帘维修版本与历史工序追算

- **版本快照**：纸帘每次“建帘/维修”形成一条不可变快照，记录维修日期、修后丝径、修后帘纹间距与推算密度。台帐可查看每张帘的版本档案，并可补录或补改早期维修。
- **按工序日期时点匹配**：抄纸工序只按自己的工序日期匹配“当天以前最近一版”纸帘参数（`matchedVersionId/standardGap`），绝不用现在档案里的最新值回头计算历史工序；工序日期早于任何版本时为 `待补录`，不能算合格。
- **连带重算**：补录或修改早期维修后，在单个 IndexedDB 事务内连带重算该帘之后工序的偏差与参数状态，并把受影响的成纸样本转“待复检”。
- **样本复检门控**：受影响样本先保留原归档位与冻结的历史结论，再标待复检；复检没通过前不得恢复归档，复检通过才恢复（位置不变）。每次复检都留记录。
- **批量保存原子性**：重算批次任一步失败会整体回滚、恢复上次结果，杜绝工作台/抄纸工序/样本卡显示半批结果；失败批次留痕（含未保存的尝试明细），纸帘置“待重算”标记，可在台帐“重试重算”。
- **导出留痕**：JSON 与 CSV 同时带上维修版本快照、每槽工序的重算前/后结果以及全部复检记录。

## 核心功能与路由表

| 路由 | 页面标题 | 核心功能 |
| --- | --- | --- |
| `/` | 工作台 | 查看纸帘状态分布、本周工序数、待复检样本与标准工序路径 |
| `/moulds` | 纸帘台帐 | 筛选纸帘，登记新纸帘，实时推算网目密度并登记修补 |
| `/fibers` | 纤维料批台账 | 按原料和打浆度筛选、比较，展开查看关联抄纸工序 |
| `/runs` | 抄纸工序记录台 | 按日期和帘号筛选，登记工序并即时判断 ±0.2 mm 帘纹偏差 |
| `/samples` | 成纸样本与透光检验卡 | 按匀度与帘纹条数分档，查看透光帘纹预览和归档位置 |

未匹配的地址会回到工作台。
